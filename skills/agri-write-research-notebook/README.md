# agri-write-research-notebook

依計劃書撰寫繁體中文研發紀錄簿。

## 安裝

```bash
npx -y skills@latest add BeehiveDT/skill-forge -g -a claude-code -a codex -s agri-write-research-notebook
```

## 使用方式

- **書寫格式**：條列式/段落式
- **工作項目名稱**：計劃書中的工作項目名稱
- **產生的頁數**：要產生的頁數
- **詳細說明**：直接取自計劃書中對工作項目的說明即可

```text
/agri-write-research-notebook

段落式
工作項目名稱：C1 系統測試
產生的頁數：3

## 詳細說明

C1 系統測試:本階段旨在進入場域前,對系統進行...
```
